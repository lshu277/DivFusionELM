# DivFusionELM
MATLAB implementation of DivFusionELM

If you are using this code, please refer to the following article:
﻿
**"DivFusionELM: A Pruning Contribution Reinjection and Fusion Compensation Framework for Large-Scale Soil Mapping in Mining Areas Using MSI Remote Sensing Imagery"**
﻿
## Overview
﻿
This repository provides a MATLAB implementation of **DivFusionELM**, designed for large-scale soil mapping and remote sensing inversion in complex mining areas.
﻿
﻿
## Main Features
﻿
- MATLAB implementation of the DivFusionELM training and prediction workflow.
- Pruning contribution reinjection from pruned responses to retained subspace.
- Reweighted fusion compensation mechanism.
- Designed for multispectral remote sensing inversion.
﻿
## Repository Structure
﻿
This repository will include the core training code, prediction code, evaluation metrics, and supporting functions for DivFusionELM.
